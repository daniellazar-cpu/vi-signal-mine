# Vi Signal Mine

You give it a topic to mine. It goes out and collects what is being said — text, engagement, where, by which kind of source. Then it corroborates, clusters, measures stance and movement, and turns that into a report Vi can put in front of a client.

## Three modes

- **MINE**: Collect a snapshot of what is being said on a topic
- **INSIGHT**: Corroborate, cluster, measure stance and momentum across snapshots
- **REPORT**: Produce a pulse report ready to hand to a client

Momentum needs a baseline, so run MINE on a topic more than once before expecting INSIGHT to tell you what changed.

## Getting started

```bash
make install
make test
make run
```

The tool runs on `http://localhost:8811`.
